# cs-degree-2026-2029

Lecture notes and practical labs for my BSc (Hons) Cyber Security degree at Liverpool John Moores University (LJMU), 2026–2029. One folder per module, named exactly as the university names it.

## Modules

| Module | Title | Lectures | Labs |
| --- | --- | --- | --- |
| 4300COMP | [Introduction to Programming](4300COMP-Introduction-to-Programming/) (Java) | 11 | 11 |
| 4301COMP | [Computer Systems Architecture](4301COMP-Computer-Systems-Architecture/) | 11 | 11 |

## Folder layout

```text
<MODULE-CODE>-<Module-Title>/
├── Lectures/   Lecture-NN-<topic>.md
└── Labs/       Lab-NN-<topic>.md
```

## Notes

- Lectures are plain-English rewrites of the official slides with worked examples and practice questions.
- Labs are hands-on workbooks with 20 tasks each, plus an answer key. Practice tasks are not official assessment tasks.
- Code examples were compiled and run with Java 21 (`javac`) unless a lab says otherwise.
- 4301COMP scripts were run with Python 3.13, and Mermaid diagrams were checked with the Mermaid 11 parser.
