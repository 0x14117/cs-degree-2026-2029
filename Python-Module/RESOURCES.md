# Resources

Official sources come first. When a tutorial disagrees with the official documentation, the documentation wins.

## Official Python

| Resource | Link | Use it for |
| --- | --- | --- |
| Python downloads | https://www.python.org/downloads/ | Installing Python |
| Python documentation | https://docs.python.org/3/ | Everything: the final word on how Python behaves |
| The Python Tutorial | https://docs.python.org/3/tutorial/ | A second explanation of the basics |
| Built-in functions | https://docs.python.org/3/library/functions.html | `print()`, `input()`, `len()` and friends |
| `print()` reference | https://docs.python.org/3/library/functions.html#print | `sep`, `end` and other options |
| String literals and escapes | https://docs.python.org/3/reference/lexical_analysis.html#string-and-bytes-literals | `\n`, `\t`, quotes |
| Built-in exceptions | https://docs.python.org/3/library/exceptions.html | What each error type means |
| Glossary | https://docs.python.org/3/glossary.html | Looking up terms |
| PEP 8 style guide | https://peps.python.org/pep-0008/ | How professional Python code is laid out |
| PEP 20, the Zen of Python | https://peps.python.org/pep-0020/ | Python's design philosophy (`import this`) |
| Status of Python versions | https://devguide.python.org/versions/ | Which versions are supported |
