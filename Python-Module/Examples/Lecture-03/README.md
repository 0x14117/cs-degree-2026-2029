# Day 3 examples

Day 3 is about your tools, so most examples in Lecture 3 are terminal sessions rather than Python files.

| File | Used in |
| --- | --- |
| `hello.py` | Examples 3 and 7: practise running a file from the right folder, the wrong folder, and with a path |

Try this from the `Python-Module` folder:

```bash
python3 hello.py                       # fails: wrong folder
python3 Examples/Lecture-03/hello.py   # works: you gave the path
cd Examples/Lecture-03
python3 hello.py                       # works: right folder
```

On Windows, type `python` instead of `python3`.
